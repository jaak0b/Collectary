# Sharing Collections

Collectary is multi-user. You can share a collection you own with other profiles on the same
installation, or — combined with [sync](sync.md) — across devices.

## How sharing works

Every collection has an **owner** (the profile that created it). The owner grants other profiles one
of two access levels:

| Permission | Allows |
|---|---|
| **Read** | View the collection and its items, but not change anything. |
| **Write** | View and edit the collection's items. |

A shared collection appears on the recipient's **Home** screen alongside their own.

## Granting and revoking access

The owner adds a profile with Read or Write, changes the level, or revokes access. Revoking removes
the collection from that profile's view.

## Attribution

Each change records who made it. This also feeds [sync](sync.md): when the same item changes in two
places, Collectary uses the change history to detect conflicts.
